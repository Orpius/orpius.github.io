New Release: Light Theme and a Much Better Storage Experience

This update brings an improved light theme and a major upgrade to the Cloud Storage Manager. The Storage Manager now behaves much more like a desktop file system. Files can be dragged and dropped directly into folders, renamed in place, and organised in a much better way.

About Your Isolated Storage

In Orpius, every organization operates within its own single-tenant environment with dedicated, allocated storage. All data within this environment is fully encrypted and accessible only to authorized members of your organization.

Orpius storage is a shared working environment for both your team and your AI Agents. This allows for autonomous management:

  • AI Agents can create, modify, move, or delete files based on your needs. They can also list directory contents.

  • AI Agents can generate office documents, including spreadsheets, Word documents, and PowerPoint presentations—as well as PDFs and other file types, saving them directly into your shared storage.

  • While you can manage files manually, you can also perform any file operation simply by asking Orpius in the chat.

Instant Publishing via the Web Directory

Every organization includes a public /web folder designed for instant hosting. This directory is your automated publishing hub:

  • Any file placed in /web is automatically live and accessible via a public link.

  • When your AI Agents generate HTML content, they save it directly to this folder.

  • Your Agent will provide the live link immediately after a task, or you can ask in the chat for a list of your hosted URLs at any time. A link to your web directory is also provided at the the top navigation bar where your Space name is displayed, just click the expand button to reveal it.

Note: Because this folder powers your hosting, it is a reserved system directory and cannot be renamed.
